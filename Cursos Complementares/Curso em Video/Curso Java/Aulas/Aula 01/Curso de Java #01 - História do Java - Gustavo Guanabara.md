# Curso de Java #01 - História do Java
**Professor:** Gustavo Guanabara | **Canal:** Curso em Vídeo

Este documento apresenta um resumo aprofundado e minucioso da primeira aula do curso de Java, que aborda desde os primórdios da computação até a consolidação do Java como uma das tecnologias mais presentes no nosso dia a dia.

## 1. O Início: Computadores Sem Linguagem
Para entender o propósito do Java, é preciso voltar aos primeiros computadores, como o lendário **ENIAC**. Essas máquinas colossais, construídas à base de válvulas, não operavam no sistema binário, mas sim na base decimal. Mais importante ainda: elas não possuíam linguagens de programação, teclados ou telas de interação. A "programação" era um trabalho estritamente físico, realizado ajustando cabos e girando botões mecânicos em painéis complexos.

## 2. A Evolução para as Linguagens de Alto Nível
Com a redução de tamanho e a chegada dos computadores às mesas de trabalho, surgiram as chamadas **Linguagens de Alto Nível**. O vídeo utiliza o **Pascal** como exemplo. O grande salto tecnológico aqui foi aproximar o código-fonte da linguagem humana (normalmente o inglês). Comandos para exibir mensagens na tela, como escrever "Olá Mundo", tornaram-se intuitivos para o programador ler e estruturar.

Contudo, a máquina continua sem entender o código escrito. Ela compreende exclusivamente microinstruções em linguagem de baixo nível. Para resolver isso, surgiu a figura central do **Compilador**: um software especializado em receber o código-fonte de alto nível e traduzi-lo integralmente em um arquivo executável, agora perfeitamente compreensível pelo computador.

## 3. O Paradigma da Linguagem C e a Multiplataforma
O processo inicial de compilação tinha um obstáculo severo: a dependência de plataforma. Um código compilado em um ambiente (como o MS-DOS) não era executável em outros (como Linux ou macOS). 

A **Linguagem C** entrou em cena para revolucionar esse cenário. Ao programar em C, tornava-se possível compilar o mesmo código-fonte em compiladores diferentes, específicos para cada plataforma, gerando um executável adequado para cada uma delas. Esse princípio de "multiplataforma" foi tão bem-sucedido que o C se tornou a fundação dos grandes sistemas operacionais (Windows, Linux, macOS) e de aplicações robustas.

Com o tempo, o C evoluiu para o **C++**, adotando o poderoso paradigma da Orientação a Objetos. O nome da linguagem utiliza uma brincadeira sintática muito familiar para programadores de linguagens derivadas, como C, C++ e PHP, onde o operador `++` representa o incremento de uma unidade. Seguindo a mesma lógica visual de evolução, sobrepor "quatro sinais de mais" forma o símbolo `#`, resultando anos mais tarde no surgimento da linguagem **C#**.

## 4. O "Green Team" e o Nascimento do Java (1990)
Em 1990, a *Sun Microsystems* formou uma equipe interna focada em inovação batizada de **Green Team**, liderada pelo engenheiro **James Gosling**. O objetivo original desse projeto era bastante inusitado para a época: criar uma tecnologia que permitisse a intercomunicação entre variados eletrodomésticos e dispositivos eletrônicos de uma casa. 

Eles perceberam rapidamente que a linguagem C++ não oferecia a flexibilidade necessária para esse ecossistema autônomo. Decidiram, então, criar sua própria linguagem. O primeiro nome provisório foi *Green Talk*, sendo logo alterado para **Oak** (Carvalho), inspirado em uma enorme árvore de carvalho que ficava em frente à janela do escritório de Gosling.

## 5. A Revolução Frustrada do Projeto *Star Seven (*7)*
A aplicação prática da linguagem Oak foi o dispositivo ***Star Seven***. Desenvolvido no início dos anos 90, era um aparelho portátil com tela de 6 ou 7 polegadas, sensível ao toque, conexão sem fio e integração de multimídia. Sua finalidade era atuar como uma central inteligente, permitindo controlar TV, iluminação e som. O dispositivo também apresentava o carismático mascote animado da linguagem, o **Duke**.

Apesar de ser tecnologicamente brilhante e estar décadas à frente do seu tempo (antecipando o conceito de smartphones e automação residencial), as grandes empresas de eletroeletrônicos não enxergaram potencial comercial. Ninguém quis financiar a produção em massa e, em 1992, o projeto foi tristemente engavetado.

## 6. O Encontro com a Web e o Nome "Java"
O cenário mudou radicalmente em 1994. Com Tim Berners-Lee revolucionando o mundo com a criação do HTML, a equipe da Sun percebeu que a interatividade e segurança desenhadas para o *Star Seven* serviam perfeitamente para impulsionar a incipiente Web.

Eles desenvolveram o projeto de navegador interativo *Web Runner* (posteriormente chamado *HotJava*). No entanto, um obstáculo jurídico impediu o lançamento: o nome comercial "Oak" já estava registrado por outra empresa de tecnologia.

O *Green Team* precisava de um nome novo urgentemente. Durante uma reunião de *brainstorming*, Gosling questionou o que mantinha a equipe motivada trabalhando tantas horas. A resposta unânime foi "Café". Como os programadores americanos costumam usar o termo *Java Coffee* como gíria para "café extra forte" (em menção aos cobiçados grãos cultivados na Ilha de Java, na Indonésia), o termo agradou a todos. A linguagem nascia ali com o nome **Java**, adotando a tradicional xícara fumegante como sua marca registrada mundial.

## 7. O Alerta de Marketing: Java não é JavaScript
Com a explosão de popularidade da nova linguagem, que a mídia exaltava como "o futuro da programação", grandes corporações decidiram surfar na onda. A Netscape, que estava prestes a lançar uma linguagem de script web chamada *LiveScript*, alterou seu nome de última hora para **JavaScript** em uma brilhante (porém confusa) jogada de marketing. 

O professor deixa um alerta essencial que qualquer desenvolvedor que atue com front-end e back-end descobre rapidamente na prática: **Java e JavaScript não têm nenhuma relação arquitetônica ou estrutural.** São tecnologias radicalmente distintas, servindo a propósitos diferentes, possuindo em comum apenas a jogada mercadológica no nome.

## 8. Java no Espaço, no Código Aberto e Hoje
O DNA do Java para conectar dispositivos distantes se consolidou em grandes marcos históricos e mercadológicos:
* **No Espaço:** Em 2004, a NASA enviou um robô de exploração para mapear o solo de Marte. Todo o sistema de comunicação desse rover marciano com a Terra rodava em Java.
* **Open Source:** Aderindo ao movimento de Software Livre, em 2006 a Sun disponibilizou o código da linguagem Java sob a licença GPL (juntando-se a gigantes de código aberto como Linux, Firefox, WordPress, PHP e Blender).
* **Venda para a Oracle:** Em 2009, a empresa Sun Microsystems foi adquirida pela Oracle por impressionantes US$ 7,4 bilhões. James Gosling acompanhou a transição, mas saiu da empresa um ano depois para focar em energia limpa.

Atualmente, o domínio do Java é irrefutável. A linguagem é o motor por trás de cartões de crédito (os chips *SmartCard* usam interfaces em Java), sistemas de *Homebanking*, leitores digitais como o Kindle, toda a interatividade do Blu-Ray, o padrão de TV Digital Brasileira (sistema Ginga), o programa da Receita Federal (Imposto de Renda) e, principalmente, **a imensa maioria dos aplicativos nativos no ecossistema Android** (incluindo apps cruciais como WhatsApp e bancos).

## 9. Considerações Finais e Foco Prático
A aula se encerra estabelecendo o tom do curso. Antes de partir para instalação de JDK e escrita de código, era vital entender as dores, a origem e a filosofia que moldaram a linguagem. O curso promete fugir das explicações teóricas monótonas que costumam assombrar as aulas de programação em ambientes tradicionais, garantindo uma imersão prática com criação de aplicativos visuais desde o início da jornada.
